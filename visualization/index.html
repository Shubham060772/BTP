01 — Evolution

How We Got Here

The journey from basic collaborative filtering to hybrid Transformer-GNN models.

2009

Matrix Factorization & BPR

UAI / IEEE Computer

Koren et al. and Rendle et al. establish MF and pairwise ranking for implicit feedback. The foundation of modern recommender systems.

Limitation: Linear, no higher-order user-item relationships. Cannot capture complex behavioral patterns.
2017-2018

Attention & Sequential Models

IEEE ICDM 2018

SASRec applies causal self-attention to user interaction sequences. Learns which past items matter for predicting the next one. BERT4Rec (CIKM 2019) adds bidirectional attention with masked prediction.

Limitation: Processes each user independently. No collaborative signal from similar users. Needs dense interaction history to work well.
2019-2020

GNN-based Collaborative Filtering

ACM SIGIR 2020

LightGCN removes all neural components from GCN (no transforms, no activations) and shows that pure neighborhood aggregation is all you need. 16-22% better than NGCF.

Limitation: No sequential modeling. Treats interaction history as a set. Uniform layer weights — not personalized. Ignores metadata.
2021-2023

Contrastive Learning Era

ICLR / SIGIR / TKDE

SGL, SimGCL, LightGCL add self-supervised contrastive objectives to GNN-CF. LightGCL (ICLR 2023) achieves 83% improvement over LightGCN on Amazon-Book using SVD-based augmentation.

Limitation: Still no sequential modeling. Still no Transformer component. Purely graph-based collaborative filtering.
2024

First Hybrid: SASGCN

IEEE Access 2024

SASGCN combines SASRec + GCN for the first time. Uses GCN for collaborative signal and self-attention for sequential patterns.

Limitation: Uses vanilla GCN (not LightGCN). Static concatenation+MLP fusion — same fusion strategy for all users. No analysis of when each signal helps. Only 5 citations.
2026

Our Proposal: AdaFuse

PROPOSED

AdaFuse upgrades SASGCN with LightGCN (proven superior), replaces static fusion with a learned per-user attention gate, and analyzes when sequential vs. collaborative signals dominate.

02 — Key Papers

Papers That Define the Landscape

The most important papers we surveyed, with their verified publication details and identified limitations.

SASRec

2018
IEEE ICDM

Causal self-attention over item sequences. Balances long-term preferences with short-term intent through positional embeddings and multi-head attention.

Limitation

Each user encoded in isolation. No information flows between users — misses collaborative signal entirely.

BERT4Rec

2019
ACM CIKM

Bidirectional Transformer with Cloze (masked item prediction) objective. Sees future context during training.

Limitation

Train-test mismatch (masks during training, predicts future at test). Needs 30x training time. Highly sensitive to mask ratio.

LightGCN

2020
ACM SIGIR

Removes feature transforms and nonlinear activations from GCN. Only neighborhood aggregation + layer combination. Simple yet powerful.

Limitation

No sequential modeling. Uniform layer weights (not personalized). Authors suggest per-user layer attention as future work.

SASGCN

2024
IEEE Access

First combination of SASRec + GCN. GCN captures collaborative patterns; self-attention captures sequential interests. Simple concatenation+MLP fusion.

Limitation — Our Target

Uses vanilla GCN (not LightGCN). Static fusion treats all users identically. No sparsity analysis. No study of when each signal helps.

SG-MST

2024
IEEE ICDM

Hypergraph-enhanced contrastive Transformer for multi-behavior e-commerce. Models views, clicks, carts, and purchases separately.

Limitation

Requires multi-behavior datasets. Complex hypergraph construction. Contrastive regularization adds hyperparameters.

TGT

2022
IEEE TKDE

Temporal Graph Transformer for multi-behavior sequential recommendation. Captures dynamic short/long-range patterns across behaviors.

Limitation

Requires multi-behavior data. Complex temporal encoding. Difficult to reproduce.

MGUI

2026
IEEE TCSS

Multi-grained user interests with item-transition graph propagation and user-specific mixture-of-experts for sequential recommendation.

Limitation

MoE adds complexity. Item-transition graph is computed from sequences (no bipartite user-item graph). Very recent — limited reproducibility info.

LightGCL

2023
ICLR

SVD-based deterministic graph augmentation for contrastive learning. Current SOTA on Amazon-Book (Recall@20=0.0585).

Limitation

No sequential component at all. Purely collaborative. Single augmentation view. Uniform spectral treatment.

03 — Flaws & Fixes

What's Broken & How We Fix It

Specific limitations in prior work and our targeted solutions.

Flaw 1 — SASGCN

Vanilla GCN Instead of LightGCN

SASGCN uses vanilla GCN with feature transforms and activations. LightGCN proved these hurt CF performance (16-22% worse). Using the wrong GNN backbone limits the collaborative signal quality.

Flaw 2 — SASGCN

Static Fusion for All Users

Concatenation + MLP gives every user the same fusion strategy. But a user with 3 interactions needs different treatment than one with 300. Static fusion can't adapt.

Flaw 3 — SASRec

No Collaborative Signal

SASRec processes each user independently. A new user with 2 interactions gets terrible recommendations because there's no information from similar users.

Flaw 4 — LightGCN

No Sequential Awareness

LightGCN treats the interaction history as a set. Buying "Laptop, Mouse, Keyboard" in that order or any other order produces identical recommendations. Recent intent is lost.

Flaw 5 — All Prior Hybrids

No Sparsity-Stratified Analysis

No paper systematically analyzes when sequential signal dominates vs. when collaborative signal dominates across different user activity levels.

Fix 1 — AdaFuse

LightGCN as GNN Backbone

Replace vanilla GCN with LightGCN. Pure aggregation without transforms or activations. Proven 16-22% better for recommendation tasks.

Fix 2 — AdaFuse

Learned Per-User Attention Gate

α(u) = σ(wT · [eseq; ecol; eseq ⊙ ecol]). Each user gets a personalized fusion weight. The model learns who needs what.

Fix 3 — AdaFuse

GNN Branch Provides Collaboration

LightGCN propagates information through the user-item graph. Even users with few interactions inherit rich representations from their graph neighborhood.

Fix 4 — AdaFuse

Transformer Branch Models Sequences

SASRec captures temporal patterns and recent intent. "Laptop → Mouse → Keyboard → ?" uses attention to predict the next likely item.

Fix 5 — AdaFuse

Sparsity-Stratified Evaluation

Group users by interaction count. Report per-group metrics. Analyze α vs. density. Show that sparse users lean on GNN, active users lean on Transformer.

04 — Architecture

AdaFuse Model Design

Adaptive attention fusion of sequential and collaborative representations.

📚

Input Data

User interaction sequence Su = [i1, i2, ..., it] + User-Item Graph G = (U ∪ I, E)
⚡

SASRec (Transformer)

Causal self-attention over item sequence. Learns temporal patterns and recent user intent.
eseq(u) = SASRec(Su)
🌐

LightGCN (GNN)

Multi-hop neighborhood propagation. Captures collaborative patterns from similar users.
ecol(u) = LightGCN(G)
⚖

Adaptive Attention Fusion Gate

Per-user learned weight decides how much sequential vs. collaborative signal to use. Sparse users get more GNN; active users get more Transformer.
α(u) = σ(wT · [eseq; ecol; eseq ⊙ ecol])   |   efinal = α · eseq + (1-α) · ecol
🎯

BPR Ranking

Score items using fused representation. Train with Bayesian Personalized Ranking loss.
L = LBPR + λ · ||Θ||²
05 — Research Questions

What We're Investigating

Four specific, testable research questions that drive the experiments.

RQ 1 — Performance

Does adaptive fusion beat static fusion?

Does AdaFuse's attention-based adaptive fusion outperform SASGCN's static concatenation+MLP fusion, and individual SASRec and LightGCN baselines?

RQ 2 — Interpretability

Does fusion weight correlate with user activity?

How does the learned fusion weight α(u) correlate with user interaction density? Do sparse users rely more on GNN collaborative signal?

RQ 3 — Ablation

What does each component contribute?

What is the individual contribution of the Transformer branch, the GNN branch, the attention gate, and the element-wise interaction term?

RQ 4 — Robustness

How does it handle data sparsity?

How does AdaFuse perform under varying training data density (100% / 75% / 50% / 25%) compared to single-signal baselines?

The Key Insight We Expect

The learned attention weight α should correlate with user activity level:

Sparse users (1-5 items) — α ≈ 0.3, rely on GNN
Medium users (10-30 items) — α ≈ 0.5, balanced
Active users (30+ items) — α ≈ 0.7, rely on Transformer

Contribution Statement

"We propose AdaFuse, a hybrid recommendation model that combines SASRec (Transformer) and LightGCN (GNN) through a learned per-user attention gate. Unlike SASGCN (IEEE 2024) which uses static fusion, AdaFuse adaptively determines how much sequential vs. collaborative signal each user needs. Experiments on Amazon-Beauty and Amazon-Book show AdaFuse outperforms static fusion, with sparse users benefiting more from GNN signal and active users from Transformer signal."
